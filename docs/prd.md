# SnapBug 产品需求文档（PRD）

> **关联文档**：[需求背景](./background.md) · [技术选型](./tech-stack.md)  
> **视觉与布局参考**：极简白蓝 Bento 工作台（无硬边框白卡片、实心蓝选中导航、冰蓝左竖条列表、列表/卡片双视图与右侧抽屉详情）。

## 1. 产品概述与核心设计原则

**SnapBug** 是一款面向中小型研发与测试团队的轻量级研发协作工作台，定位为禅道的极简现代替代方案。

**核心产品原则**：

1. **极简层级**：业务结构严格封顶为 `项目 → Bug` 单层，不设强制配置的功能模块树、版本树或迭代套娃。
2. **零配置协作**：通过「指派即授权」机制自动完成项目成员加入，免去手动配置项目权限的行政开销。
3. **AI 融入高频痛点**：在提 Bug 描述重构、个人笔记提炼、工作月报/周报润色三个高频文字环节提供开箱即用的 AI 提效。
4. **协作与个人空间合一**：团队缺陷追踪按项目归类，个人笔记、工作计划与工作汇报跟随个人账号跨项目全局可用。

---

## 2. 角色体系与权限模型

系统采用极简双角色设计，不做复杂的功能按钮级 RBAC 隔离：

| 角色           | 账号来源                                                      | 登录后视角                                                    | 核心权限                                                                                                               |
| -------------- | ------------------------------------------------------------- | ------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| **超级管理员** | 系统初始化预置默认账号 `admin / admin123`（支持环境变量覆盖） | **专属极简成员管理页**（不混杂研发工作台）                    | 仅负责成员管理：单个新增成员、Excel 批量导入成员、编辑成员信息、重置密码、启用/禁用账号                                |
| **普通成员**   | 由超级管理员单个创建或 Excel 批量导入（账号/邮箱 + 密码登录） | **完整研发工作台**（工作台 / Bug 追踪 / 个人笔记 / 工作计划） | 创建项目、在已加入项目内平权协作（提 Bug、修改状态、转派、评论）、维护个人笔记与计划、生成汇报、修改个人密码与头像昵称 |

### 2.1 项目权限与「隐式自动授权」规则

- **创建即加入**：任何普通成员新建项目时，自动成为该项目成员。
- **指派即授权**：在项目中新建 Bug 或转派 Bug 时，指派人下拉列表支持选择**全团队任意在职（启用）成员**；一旦将 Bug 指派给成员 B，系统**自动将成员 B 加入该项目的成员列表**，B 立即获得该项目的访问与协作权限，无需额外配置。
- **数据可见范围**：普通成员在「工作台」和「Bug 追踪」中仅可见**自己已加入的项目**及其下的 Bug；个人笔记与工作计划仅本人可见。

## 3. 全局交互框架

### 3.1 登录页

- 沿用清爽白蓝双栏风格：左侧展示 SnapBug 品牌与核心能力亮点，右侧为真实账号登录表单（账号/邮箱 + 密码 + 保持登录状态）。
- 根据登录角色自动分流：超管进入「成员管理」，普通成员进入「工作台」。

### 3.2 主应用框架（普通成员视角）

- **顶部导航栏（56px）**：
  - 左侧：`SnapBug` 品牌标识。
  - 右侧：
    1. **「+ 快速提 Bug」** 主操作按钮；
    2. **快捷搜索图标**：点击跳转「Bug 追踪」并自动聚焦搜索框；
    3. **消息通知图标**：带未读数红色角标，Hover/点击展开下拉通知面板；
    4. **个人头像与姓名**：Hover 展开菜单（生成工作汇报、个人设置/修改密码、退出登录）。
- **左侧导航栏（212px）**：
  - 顶部主入口：**工作台**；
  - 分组「研发协作」：**Bug 追踪**（右侧显示指派给我的未关闭/未忽略 Bug 数量角标）；
  - 分组「个人空间」：**个人笔记**、**工作计划**；
  - 底部快捷提示：`按 C 快速提单`。
- **全局快捷键**：
  - `C`：在非输入状态下，任意页面快速唤起「快速提 Bug」弹窗；
  - `Esc`：关闭当前打开的弹窗或右侧详情抽屉。

## 4. 功能模块详细需求

### 4.1 超级管理员：成员管理

超管登录后直接进入单页「成员管理」，保持极简专注：

1. **成员列表**
   - 展示字段：姓名、登录账号/邮箱、岗位标签（如前端开发/后端开发/测试工程师，纯展示用）、账号状态（启用/禁用）、创建时间。
   - 支持按姓名/账号搜索与状态筛选。
2. **单个添加与维护**
   - 新增成员：姓名（必填）、登录账号/邮箱（必填、唯一）、初始密码（必填或默认初始密码）、岗位标签（选填）。
   - 操作：编辑基本信息、重置密码、启用/禁用账号（禁用后无法登录且不出现在新 Bug 指派候选列表中，历史 Bug 仍保留其姓名展示）。
3. **Excel 批量导入**
   - 提供标准 `.xlsx` 导入模板下载（列：姓名、登录账号/邮箱、初始密码、岗位标签）。
   - 上传 Excel 后由后端解析校验：校验必填项、邮箱/账号格式及重复性，返回导入结果摘要（成功导入条数、跳过/失败行号及原因明细）。

### 4.2 工作台（Dashboard）

采用 Bento 双栏布局，作为普通成员登录后的默认首页：

- **口径切换**：左侧缺陷统计卡片与趋势卡片默认汇总**“我参与的所有项目”**数据，卡片右上角提供轻量「项目筛选下拉框」（全部项目 / 单个项目）。
- **左侧主区**：
  1. **本周缺陷数据卡片**：
     - 累计 Bug 总数 + 本周已关闭增量；
     - 状态分布环形图（待处理 / 处理中 / 待验证 / 已关闭 / 已忽略）及各项计数；
     - 底部 3 个子 KPI：指派给我（含待处理数）、我提交的（含已解决数）、AI 优化单（含规范率）。
  2. **今日工作计划卡片**：
     - 顶部展示当前周日历条（支持点击切换查看本周任意日期的计划，支持「回到今日」）；
     - 蓝点时间轴展示选中日期的计划项，点击条目可直接勾选完成/取消完成。
  3. **常用操作磁贴（6 宫格）**：
     - 快速提 Bug、AI 优化提单、Bug 卡片墙、新建笔记、工作计划、生成汇报。
  4. **近 7 日缺陷流转趋势卡片**：
     - 汇总指标：近 7 日新增数、已关闭数、平均响应时长、关闭率；
     - 双曲线面积图：近 7 日每日新增 vs 每日已关闭趋势。
- **右侧信息栏**：
  1. **个人问候卡片**：动态时段问候语、头像、岗位标识。
  2. **个人笔记速览**：冰蓝左竖条展示最近编辑的 4 篇笔记，点击直达编辑；快捷按钮「+ 新建笔记」。
  3. **指派给我的 Bug**：展示最近指派给自己的 4 条未完结 Bug，点击直接打开右侧详情抽屉。

### 4.3 项目与 Bug 追踪（核心模块）

#### 4.3.1 轻量项目管理

- 入口位于「Bug 追踪」页面顶部工具栏：
  - **项目筛选下拉框**：默认「全部项目（我参与的）」，可切换至单个项目；
  - **「+ 新建项目」按钮**：弹出极简弹窗，仅需填写**项目名称**（必填）与**项目简介**（选填），提交后自动加入该项目并立即可用于提 Bug。

#### 4.3.2 Bug 列表与卡片双视图

- **视角 Tab**：`指派给我的`（默认）/ `我提交的` / `团队全部`（限我参与的项目）。
- **工具栏**：项目筛选、关键词搜索（支持搜 `BUG-xxx` 编号与标题）、状态筛选（全部 / 5 种状态）、**列表 / 卡片视图切换器**（切换视图时保留当前搜索与筛选条件）。
- **列表视图（Table）**：列包含 编号、问题描述（含 `AI 优化` 标签与附件小图标）、所属项目、优先级、状态（支持行内下拉直接修改）、指派人、更新时间。
- **卡片视图（Card）**：按优先级展示左侧色标（P0 红 / P1 橙 / P2 蓝），展示编号、优先级、状态快捷下拉、标题、两行摘要、所属项目、附件数、指派人、评论数与更新时间。

#### 4.3.3 快速提 Bug 弹窗

- **极简表单字段**：
  1. **所属项目**（必填，默认记忆用户上次选择的项目；若尚无项目可引导快速创建）；
  2. **问题标题**（选填；若留空且触发了 AI 优化则由 AI 自动生成，直接提交时若留空则截取描述前 28 字）；
  3. **问题描述**（纯文本输入区，确保内容干净便于 AI 结构化重构）；
  4. **媒体附件（图片 + 视频）**：
     - 支持 `Ctrl+V` 直接在弹窗中粘贴剪贴板截图，或拖拽/点击上传图片与录屏视频；
     - 支持格式：图片（`png / jpg / jpeg / webp / gif`）、视频（`mp4 / webm / mov`）；
     - 采用**云对象存储（阿里云 OSS / 腾讯云 COS）客户端直传**，上传中显示进度条，上传完成展示缩略图/视频封面，支持删除与预览；
  5. **指派给**（必填，全团队启用成员可选；提交后自动赋予对方该项目权限）；
  6. **优先级**（必填，默认 `P1`）：`P0 · 紧急阻断` / `P1 · 重要问题` / `P2 · 一般优化`。
- **AI 一键优化**：
  - 点击「AI 一键优化」后，调用后端流式接口将口语化描述重构为标准结构：
    - `【问题描述】`
    - `【复现步骤】`
    - `【预期结果】`
    - `【实际结果】`
  - 若标题为空，AI 同步生成简洁准确的问题标题；
  - 优化完成后提供**「撤销 / 还原原文」**按钮，防止 AI 误改；确认提交后该 Bug 标记 `aiOptimized = true`。

#### 4.3.4 Bug 状态机与协作联动

- **5 种状态**：
  - `open`：**待处理**（新提交默认状态）
  - `progress`：**处理中**
  - `verify`：**待验证**
  - `closed`：**已关闭**
  - `ignored`：**已忽略**（用于“非 Bug / 需求如此 / 无法复现 / 暂不修复”，与真正修复关闭区分开）
- **自由流转与智能联动**：
  - 支持在列表、卡片和详情抽屉直接切换任意状态，不强弹繁琐确认框；
  - **待验证回指联动**：当状态被修改为 `verify`（待验证）时，若当前指派人不是提单人（`creator`），系统**自动将指派人切回提单人**，并向提单人发送验收通知；
  - 支持在详情抽屉随时转派给其他团队成员（同样触发隐式项目授权与转派通知）。

#### 4.3.5 右侧 Bug 详情抽屉

- **头部**：Bug 编号（如 `BUG-104`）、`AI 优化` 标识、**「加入今日计划」**快捷按钮、关闭按钮。
- **元信息区**：标题、所属项目、提单人与提交时间、可交互的状态下拉框、可交互的指派人下拉框、优先级标识（支持修改）。
- **正文与附件**：格式化展示问题描述；下方展示图片与视频附件（点击图片灯箱放大缩放，点击视频弹窗/内嵌播放，私有桶通过短期签名 URL 访问）。
- **处理记录与活动时间线**：
  - 按时间顺序融合展示**系统自动日志**（如“苏晴 创建了此 Bug”“林默 将状态从 处理中 改为 待验证，并自动指派给 苏晴”）与**人工评论**；
  - 底部提供评论输入框，支持回车快速发送。

---

### 4.4 站内消息通知

- **通知机制**：仅做轻量站内通知，不接入外部 IM 或邮件推送，通过 SSE 或轻量轮询实现未读红点近实时刷新。
- **触发事件**：
  1. 新建 Bug 指派给你（本人指派给自己不重复通知）；
  2. Bug 转派给你；
  3. 你提交的 Bug 状态变为「待验证」（待验收提醒）；
  4. 你相关的 Bug（作为提单人或当前指派人）收到他人的新评论。
- **交互**：顶部信封角标显示未读总数；Hover/点击展开通知列表，支持单条点击（自动标为已读并直接打开对应 Bug 详情抽屉）以及「全部已读」。

---

### 4.5 个人笔记（纯私有）

- **可见性**：完全私有，仅创建人本人可见、可编辑、可删除。
- **交互布局**：左侧笔记列表（按更新时间倒序、支持搜索标题/正文、新建按钮）+ 右侧编辑器。
- **Markdown 编辑与自动保存**：
  - 支持标题输入 + Markdown 正文编辑（支持编辑/预览切换或分屏预览）；
  - 支持编辑器内 `Ctrl+V` 粘贴截图自动直传 OSS/COS 并插入 Markdown 图片语法；
  - 输入防抖自动保存，顶部实时显示「保存中 / 已自动保存 · 时间」。
- **AI 提炼要点**：点击「AI 提炼要点」，基于当前笔记正文流式生成核心结论与行动项，支持一键追加到笔记末尾或复制。

---

### 4.6 工作计划（按日期）

- **日期组织**：按自然日（`YYYY-MM-DD`）管理，与工作台周日历共享同一套数据源。
- **核心操作**：
  - 顶部展示选定日期（或本周）完成进度条与完成率百分比；
  - 快速添加栏：输入计划内容 + 可选时间点（如 `09:30` / `14:00` 或留空）+ 回车添加；
  - 分组展示「待完成」与「已完成」，支持勾选切换状态、编辑、删除。
- **与 Bug 联动**：
  - 在 Bug 详情抽屉点击「加入今日计划」后，自动在今日计划中生成一条关联 `bugId` 的待办项（如 `修复 BUG-104：订单导出报错`）；
  - 关联 Bug 的计划项显示 `BUG-xxx` 标签，点击标签可直接打开对应 Bug 详情抽屉。

---

### 4.7 工作汇报（月报 / 周报）

- **触发入口**：顶部个人菜单「生成工作汇报」、工作台快捷磁贴、工作计划页面按钮。
- **周期选择**：
  - 支持切换 **月报（默认）** 与 **周报**；
  - 支持切换具体周期（默认当前月 / 当前周，可切至上月 / 上周）。
- **数据自动汇总**：
  - 自动拉取本人在所选周期内：
    1. 已完成的工作计划；
    2. 参与修复/推进的 Bug（状态进入待验证/已关闭的本人处理单，以及当前仍在进行中的单）；
    3. 尚未完成的待推进计划。
  - 自动拼装成结构清晰的基础 Markdown 汇报草稿，允许用户自由编辑。
- **AI 一键润色**：
  - 点击「AI 一键润色」，由 AI 将零散的条目与 Bug 标题整合提炼为条理清晰、适合直接发给团队或上级的专业月报/周报；
  - 支持「还原原始草稿」与「一键复制 Markdown」。

### 4.8 AI 协作增强规划（字段已预留，后续按阶段开发）

> 以下 4 项围绕「团队历史上下文」的 AI 增强能力**暂不纳入首期开发**，数据库字段（`bugs.related_bug_id`、`bugs.verify_checklist`）已在初始迁移中预留，待核心流程稳定后按优先级分批接入：

1. **相似缺陷与历史修复回溯（增强一期优先）**：
   - 提单弹窗输入标题/描述时，静默在当前 `projectId` 内检索相似历史单（重点包含**已关闭旧单**及其处理记录结论，而不仅是重复的待处理单）；
   - PG 关键词/错误码命中候选后再由 AI 解释匹配原因与历史关键排查线索，仅命中时轻展示 2~3 条；支持选择「同一个问题（跳旧单补充）」「可能是复发（写入 `related_bug_id`）」或继续提单。
2. **进「待验证」自动生成验收清单（增强一期优先）**：
   - 研发切入 `VERIFY`（可附带可选半句修复说明）时，不阻塞状态切换，异步根据描述、活动记录与修复说明生成 2~5 条具体可验证检查项，存入 `bugs.verify_checklist`（`JSONB`）；
   - 提单人点开回指通知即可逐项勾选通过/不通过；若被打回重修，下次再进 `VERIFY` 时自动把上一轮失败项置顶。
3. **提单前只追问最关键的一句（增强一期顺带）**：
   - 复用「AI 一键优化」，整理后若发现缺少最影响复现的关键信息，额外给出 1 条非阻塞轻提示问题与快捷插入位，用户可直接跳过提交，不破坏极简表单体验。
4. **长时间线进展摘要（增强二期）**：
   - Bug 经历多轮转派、评论与重开后，抽屉按需生成短摘要（已确认的现象、已排除的原因、下一步验证项），每条附带锚点跳回对应评论或活动记录。

## 5. 非功能性与边界约定

1. **云对象存储与安全**
   - 所有图片与视频附件**禁止落盘应用服务器**，统一通过后端签发临时上传凭证（预签名 URL / STS）由前端直传阿里云 OSS 或腾讯云 COS；
   - 后端签发凭证前严格校验用户登录态、文件 MIME 类型与单文件体积上限（建议默认：单张图片 ≤ 10MB，单个视频 ≤ 50MB，可配置）；
   - 附件存储桶建议配置为**私有读写**，前端展示时通过后端签发的短期预览 URL 访问，避免业务截图外泄。
2. **系统配置方式**
   - AI 模型接入（OpenAI 兼容 Base URL、API Key、Model 名称）、对象存储配置（厂商/Bucket/凭证）及默认超管凭据均通过后端 `.env` 环境变量统一配置，不在前端页面暴露复杂系统设置。
3. **基础体验要求**
   - 登录态过期（HTTP 401）自动清理本地 Token 并平滑跳转登录页；
   - 所有列表与卡片具备清晰的空状态引导与加载骨架屏；关键写操作防连点重复提交，并配以轻量化 Toast 反馈。
